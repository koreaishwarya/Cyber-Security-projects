# Password Strength Analyzer & Custom Wordlist Generator
## 🌐 Live Demo

👉 [Open Password Strength Analyzer](https://secops-toolkit-dva7.arcada.app)
## Objective
Analyze password strength and generate attack-specific custom wordlists.

## Features
- Password strength analysis using zxcvbn
- Entropy and crack-time estimation
- Custom wordlist generation
- Leetspeak substitutions
- Year and symbol appending
- TXT export support

## Technologies Used
- Python
- zxcvbn
- NLTK
- argparse

## Installation

pip install zxcvbn nltk

## Run

python main.py

## Output

generated_wordlist.txt

## Educational Purpose

This project is intended for cybersecurity education and authorized security testing only.
